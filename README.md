# 🎬 VFX Pipeline AI (`vfx-pipeline-ai`)

An open-source, AI-powered Python toolkit designed to assist 3D Animators, VFX Compositors, and Technical Directors in automating workflows across **Foundry Nuke**, **Autodesk Maya**, and **Blender**.

## ✨ Key Features
* **Smart Node-Graph Assistant:** Generate and optimize Nuke Python scripts and TCL expressions using natural language prompts.
* **Automated Error Analyzer:** Parse render logs and compositing script errors to provide instant troubleshooting fixes.
* **Batch AOV & Asset Manager:** Automate multi-pass AOV setups, unpremult/premult workflows, and 3D asset naming conventions.
